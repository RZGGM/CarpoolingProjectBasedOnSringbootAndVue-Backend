# websocket的开发

## 后端

在登录成功后，要保存客户端和服务端的会话对象。并且要用标识，标识可选择jwt或是用户的id。

在登录成功时先记录下用户的jwt用于作保存会话对象的标识。

并且在客户端和另一个客户端进行通信时，也要用到另一个客户端的会话对象，所以最好用id吧。

但是因为登录用的是帐号，所以用ID的话，可能会得到另一个身份的信息。

所以用jwt吧。

大概是连接登录成功后，就保存好会话连接，然后在一个用户发送信息时，要判断哪些用户可以收到，
然后再发送给他们。

那因为我的项目是将消息发送到用户所共用的聊天室里，所以可以将会话的标识设置为聊天室的id。

然后在用户发送消息时，根据聊天室的id判断当前哪些会话要接收到。
